# Nyx IDE

Середовище програмування для [NyxilumLang](../NyxilumLang), написане **на самій NyxilumLang**.
Для всіх, хто починає програмувати, і для тих, хто вже вміє.

- **Код** - редактор з підсвіткою, автовідступами, скасуванням, запуском (F5) і консоллю,
  у якій програма може питати й отримувати відповіді (`readLine`).
- **Блоки** - режим як у Scratch: палітра, перетягування, запуск, «Показати код».
- **Навчання** - уроки з автоперевіркою і «Покажи мені», приклади. Детально - [ПОСІБНИК.md](ПОСІБНИК.md).

## Запуск

Найпростіше - з релізу [NyxilumNode](https://github.com/Faneraiy14/NyxilumNode)
(IDE вже лежить в архіві поруч з `nx`):

```bash
nx ide                     # програми в ~/NyxПрограми
nx ide ~/МояТека           # або у вказаній теці
```

З клону цього репо:

```bash
nx src/ide.nx
NX_IDE_HOME=/шлях/до/NyxilumIDE nx ide
```

Потрібен `nx` з полотном `surface*` (NyxilumLang після 14.10.2026).

## Гарячі клавіші

| Клавіші | Дія |
|---|---|
| F5 / Ctrl+R | запустити / зупинити |
| Ctrl+S | зберегти (і так зберігається перед запуском і при виході) |
| Ctrl+Z / Ctrl+Y | скасувати / повторити |
| Ctrl+C / Ctrl+X / Ctrl+V | копіювати / вирізати / вставити (без виділення - весь рядок) |
| Ctrl+A | виділити все |
| Ctrl+/ | закоментувати рядки |
| Ctrl+D | дублювати рядок |
| Tab / Shift+Tab | відступ / прибрати відступ |
| Ctrl+= / Ctrl+- / Ctrl+колесо | шрифт більший / менший |
| Ctrl+N | нова програма |
